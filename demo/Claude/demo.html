Horizontal customizable <select multiple> listbox

Two demos using native HTML, styled with appearance: base-select — no JS framework, no div-soup dropdown.

Your browser doesn't support appearance: base-select yet, so these will fall back to a plain native multi-select list. This feature currently needs a recent Chromium browser (Chrome/Edge 133+).

Demo 1 — Segmented pill row (like a chat/cowork toggle)

This one hides the checkmark and shows selection purely via background — the classic "segmented control" look, allowing multiple selections since it's a multiple select.

Demo 2 — Scrollable horizontal listbox with checkmarks

This follows MDN's "Horizontal listbox" pattern directly: a flex-laid-out wrapper <div> inside the <select>, with the whole row scrolling horizontally once it overflows.
